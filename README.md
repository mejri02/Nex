# KOBANI 4K Media Kit source

Flutter Android live-TV client using Media Kit.
- Loads `managedPlaylist` from the configured API.
- Filters out channel names/groups containing KURD or MUSIC.
- Shows live/sport channels with primary URL.
- Supports up to three source URLs and per-source User-Agent/Referer.
- Does not bypass DRM, authentication, geo-blocks, or provider restrictions.
- 4K/HEVC playback depends on device codec/hardware and stream profile.

Push to GitHub and download the APK from the successful Actions artifact.
